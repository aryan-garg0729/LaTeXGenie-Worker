# LaTeXGenie Parser

The **LaTeXGenie Parser** is a high-performance module designed to convert structured research content into high-quality LaTeX using IEEE or other academic formatting standards. It powers the backend of LaTeXGenie, enabling accurate and intelligent transformation of text, equations, tables, figures, code, and citations into LaTeX.

---

## ✨ Features

- ✅ Converts PDF into full LaTeX documents.
- ✅ Supports equations, figures, tables, code blocks, and algorithms.
- ✅ Intelligent escaping and formatting of LaTeX.
- ✅ Citation detection and injection (IEEE, Author-Year, etc.).
- ✅ Handles `rowspan`/`colspan` tables.
